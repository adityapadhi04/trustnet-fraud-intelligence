# TRUSTNET - React Frontend

This directory is reserved for the React single-page application.

## Planned Structure
- `src/components/`: Reusable UI elements (e.g. RiskScoreBadge, AlertCard, GraphViewer).
- `src/views/`: Primary pages (e.g. Dashboard, TransactionList, AccountDetail).
- `src/services/`: API connection layer using fetch or Axios to communicate with the FastAPI backend.
- `src/styles/`: Custom CSS files for premium dark/light mode visual presentation.

## Technology Stack
- **Framework**: React (built with Vite or create-react-app)
- **Styling**: Vanilla CSS for maximum styling flexibility and rich transitions
- **Visualization**: Plotly.js or Vis.js for interactive transaction network visualizations
